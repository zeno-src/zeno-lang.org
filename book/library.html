C The Library at a Glance

Everything that comes with Zeno, on a few pages. The chapter that explains each part is named beside it.

Functions that need no import

Function Gives
print(a, b, ...) shows the values on one line, with spaces between
input(), input(question) the next line typed, or none at the end (27)
len(x) how many items, characters or keys
range(stop), range(start, stop, step) a list of whole numbers (7)
int(x), float(x), str(x) the value as another type; int and float of text may raise ValueError
char(n) the character with Unicode number n
abs(x) x without its sign (28)
min(...), max(...) the smallest or largest, of numbers or of a list; quantities in one unit too
sum(xs) a list of numbers added up
u8(n) and u16, u32, i8, i16, i32 n as a sized number, or OverflowError (18)
u8.wrap(n) and the others the low bits of n, never failing
allocate(T, n), free(p) memory by hand (37)

Text: str

Method Gives (6)
upper(), lower() capitals or small letters, a to z only
strip() without blanks at either end
split(), split(sep) a list of words, or of the pieces between each sep
lines() a list of the lines
replace(old, new) every old made new
starts_with(s), ends_with(s) bool
find(s) a position, or none
slice(from, to), slice(from) a part
code() the Unicode number of a one-character text

Lists: list[T]

Method Does (9)
append(x), insert(at, x) adds an item
pop(), pop(at) takes out the last item, or the one at at, and gives it
clear() takes out every item
reverse(), sort() in place
sort(by) in place, in the order of the key by gives for each item
find(x) a position, or none
slice(from, to), slice(from) a new list of a part
join(sep) for text: one text with sep between
map(f), filter(f) a new list
reduce(f, start) one value

Dicts: dict[K, V]

Written Does (10)
d[key], d[key] = v reads (or KeyError), stores
key in d is it there?
get(key), get(key, instead) the value, or none, or instead
pop(key) takes the key out and gives its value
keys(), values() new lists, in the order the keys came
clear() takes every key out

The modules

Name Is
import math (28)
pi, e the numbers
sqrt(x) square root
floor(x), ceil(x), round(x) to a whole number, an int
sin, cos, tan of an angle, deg, rad or a plain number
asin, acos, atan, atan2(y, x) an angle in rad
exp(x), log(x), log2(x), log10(x) powers of e and logarithms
hypot(x, y) the distance of the point (x, y) from (0, 0)
sinh(x), cosh(x), tanh(x) the hyperbolic functions
gcd(a, b) the greatest whole number that divides both
clamp(value, low, high) the value, kept between the two
import random
between(low, high) a whole number from low to high, both included
number() a float from 0.0 up to 1.0
pick(items) one of the items of a list
seed(n) starts the numbers again from n
import time (17)
sleep(t) waits; t has a unit of time
now() a clock that only goes forward, in ms
import board (31)
led the pin of the LED
pin(n) the pin with that number
register(T, address) a register of size T
p.on(), off(), toggle(), is_on(), number what a Pin does
input_pin(n), input_pin(n, pull_up) a pin the program reads
pull_up, pull_down what holds an input when nothing drives it
b.is_high(), is_low(), number what an InputPin does
analog_pin(n) a pin whose voltage is read
a.voltage(), count(), max_count, number what an AnalogPin does
pwm_pin(n, 1 kHz) a pin switched at that frequency
w.duty(share), pulse(time), number what a PwmPin does
ticker(10 ms) a steady beat
t.wait(), ticks(), restart(), period what a Ticker does
b.interrupt(falling), rising, either the edges of an input, counted by the board
i.wait(), edges(), number what an Interrupt does
serial(n, 115200 baud) a serial port
s.write(text), write_bytes(bytes) what a Serial sends
s.read_byte(), has_byte() and what it reads
r.read(), r.write(v), r.address what a Register does, inside unsafe
import files (27)
read(path) the whole file, as text
write(path, text), append(path, text) writes, or adds to the end
exists(path) bool
remove(path) removes the file
read_bytes(path) the whole file, as a list[u8]
write_bytes(path, bytes) writes a list[u8], one byte an item
import program (27)
arguments() the words after the file
environment(name) what the environment says name is, or none
warn(text) one line on the error stream
exit(code) ends the program with code, 0 to 255; ValueError outside
import json (27)
parse(text) the value JSON text describes; ValueError if it is not JSON
write(value) a value, or an object field by field, as JSON on one line
import web (38)
element(selector) the first element that answers to it
elements(selector) every one, as a list
create(tag, text) a new element, not yet on the page
after(t, f) call f once, t later; gives a Timer
every(t, f) call f every t; gives a Timer
timer.stop() call off what it was waiting to do
on_key(f) call f with the name of each key pressed
save(name, text) keep text for the next visit
load(name), forget(name) the text kept, or none; keep it no more
fetch(address, f) ask the network; f(status, body) gets the answer
post(address, text, f) send text; f(status, body) gets the answer
e.text, e.value what it shows; what was typed into it
e.on(event, f) call f when that happens to it; f may take an Event
e.fire(event) call what on was given, now
e.append(c) put c inside it, last
e.remove(), clear() take it, or what is in it, off the page
e.add_class(c), remove_class(c) give it a class, or take one away
e.has_class(c) whether it has that class
e.show(), hide() whether it is shown
e.get(name), set(name, v) an attribute
e.set_style(n, v) the style of this one element
e.get_style(n) a style that was set, or none
e.draw_rect, draw_circle on a canvas: a filled rectangle or circle
e.draw_line, draw_text on a canvas: a line, or text
e.erase() the canvas is empty again

node.new(Class, ...) a new object of JavaScript
java.type(name), jar(path) a class of Java; where a jar is

ruby.constant(name), symbol(name) a constant of Ruby; a symbol
php.type(name), callable(name) a class, a function of PHP
php.constant(name) a constant of PHP
php.require(path), variable(value) reads a file of PHP; a variable for a function to change
lua.require(name), global(name) a module of Lua; what Lua has everywhere
csharp.type(name), assembly(path) a type of .NET; where a .dll is
copy(value) in each of the seven: a collection there, as a list or a dict of Zeno
