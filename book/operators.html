The bit operators bind tighter than the comparisons, as in Python and unlike C. So this test means what it looks as if it means, (flags & MASK) == 0:

let ready = flags & MASK == 0

The = forms

Every operator on two numbers has an = form, which updates a var, a field or an item:

+= -= *= /= //= %= **= &= |= ^= <<= >>=

x += y means x = x + y, with x read first. On a sized number the result is checked as it is stored, so count += 1 on a u8 of 255 is an OverflowError. /= is refused on a whole number, because / gives a float. A list takes += to add another list to its end.
